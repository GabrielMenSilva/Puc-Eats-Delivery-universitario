# 🍔 Puc Eats — Delivery Universitário

> Delivery universitário com os melhores restaurantes perto do campus. Promoções diárias para estudantes.

🔗 **Demo:** [gabrielmensilva.github.io/Puc-Eats-Delivery-universitario](https://gabrielmensilva.github.io/Puc-Eats-Delivery-universitario/)

🏆 Projeto premiado com **Melhor Apresentação da Etapa 1** na disciplina *Experiência Criativa: Navegando pelos Sistemas de Informação* (PUCPR).

---

## 📖 Sobre o projeto

O **Puc Eats** é um protótipo de plataforma de delivery voltado para a comunidade universitária da PUCPR, conectando estudantes aos melhores restaurantes próximos ao campus, com cupons e promoções exclusivas do dia.

## 🚀 Funcionalidades

- **Landing page** com apresentação da proposta e call-to-action ("Ver restaurantes" / "Ver promoções")
- **Autenticação** — telas de login e cadastro (`auth.html`)
- **Cardápio** — listagem de pratos e restaurantes (`cardapio.html`)
- **Ver todos** — página de listagem completa de restaurantes/pratos (`ver-todos.html`)
- **Notificações** — sistema de pop-up de promoções e ofertas do dia
- **Busca e filtros** de restaurantes, pratos e categorias

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript** (vanilla)

## 📂 Estrutura do projeto

```
Puc-Eats-Delivery-universitario/
├── index.html              → página inicial
├── auth.html / auth.css / auth.js       → login e cadastro
├── cardapio.html / cardapio.css / cardapio.js   → cardápio dos restaurantes
├── ver-todos.html / ver-todos.css / ver-todos.js → listagem completa
├── notificacoes.js / notificacoes_separado.css   → sistema de notificações
├── style.css                → estilos gerais
└── imagens/                 → imagens do site
```

## ⚙️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/GabrielMenSilva/Puc-Eats-Delivery-universitario.git
   ```
2. Abra a pasta no VS Code
3. Rode com a extensão **Live Server**, ou simplesmente abra `index.html` no navegador
